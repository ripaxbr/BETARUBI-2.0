# BETARUBI 2.0

TV mundial pública ao vivo, independente do BETARUBI original.

Stack: Flask + PostgreSQL/Neon + Vercel + Sentry.

Recursos: player YouTube, busca, favoritos, voz, Smart TV, catálogo mundial, crawler e health check.

Configure `DATABASE_URL`, `SECRET_KEY` e opcionalmente `SENTRY_DSN` no provedor. Nunca coloque credenciais no Git.
